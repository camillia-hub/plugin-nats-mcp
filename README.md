# NATS MCP

Publishes and subscribes on NATS. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/nats-mcp

Installs from the Camillia hub as `nats-mcp-f77636`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
